===========================================================
  RobloxGuard 설치 방법 (부모님용)
===========================================================

이 프로그램은 자녀가 로블록스를 몰래 실행하는 것을 자동으로 막습니다.
부모가 비밀번호로 풀어주기 전까지는 무조건 차단하고, 허용한 시간이
끝나면 저절로 다시 막습니다.

받으신 압축 파일 안에 모든 것이 들어 있습니다. 컴퓨터에 추가로 깔 것은
없습니다(.NET 같은 것 필요 없음).


-----------------------------------------------------------
[ 먼저 꼭! ] 아이 계정을 "표준 사용자"로 바꾸세요
-----------------------------------------------------------
이 전제가 없으면 아이가 결국 프로그램을 지울 수 있어 소용이 없습니다.

  1) 부모 계정(관리자)으로 로그인
  2) 설정 > 계정 > 가족 및 다른 사용자
  3) 아이 계정 선택 > 계정 유형 변경 > "표준 사용자"
  4) 관리자(부모) 계정에는 아이가 모르는 비밀번호를 걸어 두세요


-----------------------------------------------------------
[ 설치 ] 3단계
-----------------------------------------------------------
  1) 받은 ZIP 파일에서 마우스 오른쪽 클릭 > "압축 풀기"
     (ZIP 안에서 바로 실행하지 말고, 꼭 폴더로 풀어주세요)

  2) 풀린 폴더에서  Install.cmd  를 더블클릭

  3) "사용자 계정 컨트롤" 창이 뜨면 "예" 를 누르세요.
     이어서 부모 비밀번호를 정하라고 합니다(4자 이상, 두 번 입력).

끝나면 자동으로 차단이 시작됩니다. 작업 표시줄 오른쪽 아래에 자물쇠
아이콘이 생깁니다.


-----------------------------------------------------------
[ 중요 ] Windows 경고가 떠도 정상입니다
-----------------------------------------------------------
이 프로그램은 개인이 만든 것이라 Microsoft 인증서가 없습니다.
그래서 처음 실행할 때 아래 경고가 뜰 수 있습니다. 악성 프로그램이 아니라
인증서가 없어서 뜨는 경고입니다.

  * "Windows의 PC 보호" 파란 창이 뜨면:
      -> "추가 정보" 글자를 클릭 -> "실행" 버튼 클릭

  * 백신(Windows Defender 등)이 막거나 격리하면:
      프로세스를 강제로 끄고 키보드를 잠그는 동작 때문에 백신이
      의심할 수 있습니다. 보호 기록에서 "허용"으로 복원해 주세요.
      (Windows 보안 > 바이러스 및 위협 방지 > 보호 기록)

못 미더우시면 설치하지 마시고, 보내주신 분께 확인하세요.


-----------------------------------------------------------
[ 사용법 ] 자물쇠 아이콘 우클릭
-----------------------------------------------------------
  * 허용하기...   비밀번호 입력 후 30분 / 1시간 / 2시간 / 오늘 하루 선택
  * 지금 차단하기  허용 중일 때 즉시 다시 막기
  * 기록 보기...   날짜별로 아이가 몇 번 시도했는지 확인
  * 비밀번호 변경...

아이콘 색:  빨강 = 차단 중,  초록 = 허용 중,  회색 = 연결 안 됨


-----------------------------------------------------------
[ 비밀번호를 잊었을 때 ]
-----------------------------------------------------------
Install.cmd 를 다시 더블클릭하면 "비밀번호를 재설정하시겠습니까?" 에서
새로 정할 수 있습니다.


-----------------------------------------------------------
[ 제거 ]
-----------------------------------------------------------
같은 폴더의  Uninstall.cmd  를 더블클릭하세요.
서비스, 차단 설정, 프로그램 파일을 모두 지웁니다.


-----------------------------------------------------------
[ 알아두기 ]
-----------------------------------------------------------
  * 아이가 관리자 비밀번호를 알면 막을 수 없습니다(위 전제 참고).
  * 폰, 태블릿, 다른 PC 는 이 프로그램 범위 밖입니다.
  * 설치한 그 컴퓨터에서만 작동합니다.

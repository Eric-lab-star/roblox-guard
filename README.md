# RobloxGuard

가정용 Windows PC에서 자녀가 로블록스를 실행하는 것을 자동으로 막는 프로그램입니다.
부모가 비밀번호로 풀어주기 전까지는 무조건 차단하고, 허용한 시간이 끝나면 저절로 다시 막습니다.

- 로블록스 플레이어와 Studio, Microsoft Store 버전을 실행 즉시 종료합니다. 실행 파일 이름을 바꿔도 잡습니다.
- 감지되면 그 화면을 **15초 동안 잠그고** 이유를 보여줍니다.
- `roblox.com` 과 `now.gg` 같은 사이트를 hosts·방화벽으로 막습니다.
- 부모는 트레이 아이콘에서 비밀번호를 넣고 허용 시간을 고릅니다.
- 언제 몇 번 시도했는지 기록이 남습니다.

아이는 일반 사용자 계정이라 이 프로그램을 끄거나 지울 수 없습니다.

## 설치 전 준비: 아이 계정을 표준 사용자로

이 전제가 깨지면 소프트웨어만으로는 막을 수 없습니다. 아이 계정이 관리자이면
아이가 결국 프로그램을 지울 수 있습니다.

1. 부모 계정(관리자)으로 로그인합니다.
2. `설정 > 계정 > 가족 및 다른 사용자` 로 갑니다.
3. 아이 계정을 고르고 `계정 유형 변경 > 표준 사용자` 로 바꿉니다.
4. 관리자 계정에는 아이가 모르는 비밀번호가 걸려 있어야 합니다.

## 설치 — 받는 사람(부모)용

배포용 ZIP(`RobloxGuard-vX.Y.Z.zip`) 하나만 있으면 됩니다. 대상 PC에
.NET 이나 PowerShell 7 을 따로 깔 필요가 없습니다(자체 포함 빌드 +
Windows 기본 PowerShell 5.1 에서 동작).

1. ZIP 을 마우스 오른쪽 클릭 → **압축 풀기** (ZIP 안에서 바로 실행 금지).
2. 풀린 폴더에서 **`Install.cmd` 더블클릭**.
3. "사용자 계정 컨트롤" 창에서 **예** → 이어서 부모 비밀번호 설정(4자 이상).

`Install.cmd` 가 자동으로 관리자 권한을 요청하고 `install.ps1` 을 실행합니다.
설치 스크립트가 하는 일: 서비스 등록(LocalSystem, 자동 시작, 실패 시 재시작),
데이터 폴더 권한 제한, 부모 비밀번호 설정, 트레이 자동 실행 등록.
제거는 같은 폴더의 **`Uninstall.cmd`**. 자세한 안내는 ZIP 속 `설치방법.txt`.

> **Windows 경고는 정상입니다.** 개인 서명(코드 서명 인증서) 없이 배포하므로
> 처음 실행 시 "Windows의 PC 보호"(SmartScreen) 창이 뜰 수 있습니다 →
> **추가 정보 → 실행**. 백신이 프로세스 강제 종료·입력 잠금 동작을 의심해
> 격리하면 **Windows 보안 > 보호 기록**에서 허용/복원하세요. 깨끗하게
> 설치되게 하려면 코드 서명 인증서가 필요합니다("배포" 아래 참고).

## 배포 — 패키지 만드는 사람(개발자)용

개발 PC에 .NET 8 SDK가 필요합니다. 없으면:

```powershell
winget install --id Microsoft.DotNet.SDK.8 -e
```

배포용 ZIP 만들기:

```powershell
# 테스트 → 세 실행 파일 발행 → pdb 제거 → 런처·안내문 포함 → ZIP 압축
pwsh -File scripts\package.ps1
# 결과: release\RobloxGuard-v<버전>.zip  (SHA256 지문도 출력)
```

이 ZIP 을 상대 부모에게 전달하면 됩니다(위 "받는 사람용" 절차대로). 버전은
`Directory.Build.props` 의 `<Version>` 에서 읽습니다. 이미 `dist\` 에 발행본이
있으면 `pwsh -File scripts\package.ps1 -SkipBuild` 로 다시 빌드하지 않고
포장만 합니다.

직접 빌드만 하려면 `pwsh -File scripts\build.ps1` (관리자 불필요) 로 `dist\`
에 발행하고, 그 폴더에서 `Install.cmd` 를 실행해도 됩니다.

### 선택: 코드 서명 (SmartScreen 경고 없애기)

인증서가 있으면 발행된 세 exe 에 서명해 두면 받는 사람의 경고가 크게
줄어듭니다. 표준 인증서는 평판이 쌓이기 전까지 SmartScreen 이 남을 수
있고, EV 인증서는 처음부터 깨끗합니다.

```powershell
# 예시 (인증서 .pfx 보유 시)
foreach ($e in "RobloxGuard.Service","RobloxGuard.Tray","RobloxGuard.Lockout") {
  signtool sign /f cert.pfx /p <암호> /fd SHA256 /tr http://timestamp.digicert.com /td SHA256 "dist\$e.exe"
}
```

서명 후 `package.ps1 -SkipBuild` 로 포장하면 서명된 exe 가 ZIP 에 담깁니다.

## 사용법

작업 표시줄 오른쪽 트레이의 자물쇠 아이콘을 우클릭합니다.

- **허용하기…** — 비밀번호를 넣고 30분 / 1시간 / 2시간 / 오늘 하루 중 고릅니다.
  고른 시간이 끝나면 자동으로 다시 차단되고, 끝나기 5분 전과 1분 전에 알림이 뜹니다.
- **지금 차단하기** — 허용 중일 때 즉시 다시 막습니다(비밀번호 불필요).
- **기록 보기…** — 비밀번호를 넣으면 날짜별 시도 횟수와 시각을 봅니다. 기본 7일, 30일로 넓힐 수 있습니다.
- **비밀번호 변경…** — 현재 비밀번호를 확인한 뒤 새로 정합니다.

아이콘 색: 빨강=차단 중, 초록=허용 중, 회색=서비스에 연결 안 됨.

비밀번호는 가급적 **부모 계정으로 로그인해서** 입력하세요. 아이 계정 화면에서 입력하면
아이가 미리 깔아둔 프로그램이 가로챌 수 있습니다.

## 비밀번호를 잊었을 때

복구 수단은 없습니다. 관리자 권한으로 `dist\install.ps1` 을 다시 실행하면
"비밀번호를 재설정하시겠습니까?" 에서 새로 정할 수 있습니다.

## 제거

```powershell
# 관리자 PowerShell
cd dist
.\uninstall.ps1
```

서비스, hosts 차단 블록, 방화벽 규칙, 자동 실행 등록, 프로그램 파일을 모두 지웁니다.
기록을 지울지는 물어봅니다.

## 알려진 한계

- 아이가 **관리자 비밀번호를 알면** 막을 수 없습니다. 아이 계정은 반드시 표준 사용자여야 합니다.
- **다른 기기**(폰, 태블릿, 친구 PC)는 범위 밖입니다.
- 브라우저의 **DNS over HTTPS** 설정에 따라 `roblox.com` 사이트 자체는 열릴 수 있습니다.
  하지만 게임은 플레이어 실행 파일로 돌아가고 그 실행은 종료되므로 플레이는 막힙니다.
- `now.gg` 같은 **클라우드 게임**은 hosts 차단에 의존하므로 DoH 환경에서는 뚫릴 수 있습니다.
  새 서비스가 나오면 `C:\ProgramData\RobloxGuard\config.json` 의 `extraBlockedHosts` 에 도메인을 추가하세요.
- 잠금 중 **Ctrl+Alt+Del** 은 Windows 설계상 막히지 않습니다. 로그아웃·재부팅은 가능하지만
  로블록스 실행에는 도움이 되지 않습니다.
- 로블록스가 실행 파일 이름이나 회사명 메타데이터를 크게 바꾸면 판정 목록을 갱신해야 합니다.
  `config.json` 의 `extraProcessNames` 로 덧붙일 수 있습니다.
- 안전 모드 부팅, 가상 머신은 범위 밖입니다(로블록스도 그 안에서는 정상 동작하지 않습니다).

## 수동 테스트 체크리스트 (관리자 권한으로 설치한 뒤)

가장 중요한 두 가지를 먼저 확인하세요.

- [ ] 잠금 화면이 **15초 뒤 반드시 풀린다.** 검은 화면이 영원히 남지 않는다.
- [ ] `services.msc` 또는 관리자 PowerShell 에서 `Stop-Service RobloxGuard` 로 서비스를 멈추면
      떠 있던 잠금 화면이 **즉시 사라진다.**

그다음:

- [ ] 메모장이나 아무 exe 를 `RobloxPlayerBeta.exe` 로 복사해 실행 → 1초 안에 종료되고 검은 잠금 화면 + 카운트다운이 뜬다.
- [ ] 잠금 중 키보드·마우스가 막힌다. 작업 관리자(Ctrl+Shift+Esc)가 그 위로 안 뜬다.
- [ ] 잠금 중 다시 `RobloxPlayerBeta.exe` 실행 → 종료만 되고 잠금이 연장되지 않는다.
- [ ] 아이(표준 사용자) 계정으로 로그인: 트레이 아이콘이 자동 실행된다.
- [ ] 아이 계정에서 `services.msc` 로 RobloxGuard 를 **중지할 수 없다.**
- [ ] 아이 계정에서 `C:\Program Files\RobloxGuard` 를 **지울 수 없다.**
- [ ] 아이 계정에서 `C:\ProgramData\RobloxGuard` 가 **접근 거부**된다.
- [ ] 부모가 트레이에서 허용 30분 → 로블록스가 실행된다. "지금 차단하기" → 종료된다.
- [ ] 비밀번호를 5번 틀리면 5분 잠긴다("시도가 너무 많습니다").
- [ ] 허용 시간이 끝나기 5분 전·1분 전에 알림이 뜨고, 끝나면 실행 중이던 로블록스가 종료된다.
- [ ] 아이 계정에서 트레이가 서비스에 정상 연결된다(아이콘이 회색이 아니다). 비밀번호 입력창에 경고 문구가 뜬다.
- [ ] (고급) 아이 계정에서 파이프에 여러 번 연결해도 부모 계정 트레이의 허용·상태 조회가 계속 즉시 동작한다.
- [ ] `uninstall.ps1` 실행 후 서비스·hosts 블록·방화벽 규칙·자동 실행 등록이 모두 사라진다.

## 구조

- `RobloxGuard.Service` — Windows 서비스(LocalSystem). 프로세스 감시·종료, hosts·방화벽, 상태·기록, 파이프.
- `RobloxGuard.Tray` — 부모 조작 패널. 모든 세션에서 자동 실행.
- `RobloxGuard.Lockout` — 서비스가 아이 세션에 SYSTEM 권한으로 띄우는 전체 화면 잠금.
- `RobloxGuard.Core` — 모든 판단 로직(허용/차단 상태, 비밀번호, 판정, hosts 편집, 기록). 단위 테스트 대상.

데이터: `C:\ProgramData\RobloxGuard\` 의 `config.json`, `state.json`, `attempts.log`.
